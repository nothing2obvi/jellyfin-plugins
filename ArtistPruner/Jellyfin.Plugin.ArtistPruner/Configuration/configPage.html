Artist Pruner

Preview discrepancies, or remove eligible extra artist and album-artist credits on tracks and albums, supported by physical-file tags. Artist records and music files are never deleted.

Dry-run is enabled by default. Turning it off applies eligible corrections after creating a validated backup. Full mode locks affected track, album and artist metadata to prevent scans from undoing changes or deleting recovery data. Restore reverses those locks. Locked items will not automatically pick up later tag edits until restored or manually unlocked.

Unrestored recovery points are always kept. Configure recurring runs in Dashboard → Scheduled Tasks. Review proposed and applied changes in the server logs.

Proposed prunes

Run Prune Music Artists with Dry-run enabled, then show the latest report. This is the structured companion to the plugin logs, not an import of old logs. Only rows marked Proposed are eligible removals. Review-only rows are not changes. Failed/running reports are incomplete.
