Artist Pruner

Preview discrepancies, or remove eligible extra album-artist credits supported by all tracks' embedded tags. Artist records and music files are never deleted.

Dry-run is enabled by default. Turning it off applies eligible corrections after creating a validated backup. Full mode locks affected album and artist metadata to prevent scans from undoing changes or deleting recovery data. Restore reverses those locks. Locked albums will not automatically pick up later tag edits until restored or manually unlocked.

Unrestored recovery points are always kept. Configure recurring runs in Dashboard → Scheduled Tasks. Review proposed and applied changes in the server logs.

Recovery points

Restore the newest unrestored point first. Conflicting edits are preserved and cause restoration to stop.
